# Storefront (витрина)

Публичный каталог бутика: без авторизации, без онлайн-оплаты, заказ через WhatsApp. Три языка: русский в корне (`/`), казахский (`/kk`) и английский (`/en`). У каждого товара и категории есть своя страница: `/product/<slug>` и `/category/<slug>` (с префиксом языка для kk/en). SEO, hreflang, разметка и переводы описаны в [[seo]].

## Как устроена

- **Главные** (`app/page.tsx`, `app/kk/page.tsx`, `app/en/page.tsx`): серверный `StoreHome` (`components/storefront/StoreHome.tsx`) читает каталог через `getCatalog()` из `lib/catalog.ts` и передаёт его клиентскому `StorePage` (`components/storefront/StorePage.tsx`). Товары уже есть в HTML, `GET /api/products` витрина не вызывает. ISR, обновление раз в 5 минут.
- **Страницы товаров и категорий** — серверные `ProductPage` и `CategoryPage` (`components/storefront/`): хлебные крошки, галерея, цена и выгода, размеры в наличии, кнопки «В корзину» и «Заказать в WhatsApp» (`ProductActions.tsx`), похожие товары.
- **Шапка и подвал** (`SiteChrome.tsx`): логотип, переключатель языка (ссылка на ту же страницу в другом языке), ссылки на категории, доставка, WhatsApp и Instagram. Контакты и номер WhatsApp — константы в `lib/site.ts`.

## Возможности

- Hero-секция с фоновым видео `/hero-vid.mp4`: всегда стартует muted (единственный вариант автоплея, который браузеры не останавливают). Звук управляется тремя условиями: жест пользователя уже был (pointerup/touchend/keydown), скролл в hero-зоне (`scrollY < 30%` высоты экрана) и карточка товара закрыта. Все условия выполнены → fade-in ~3 сек; любое нарушено → быстрый fade-out ~0.5 сек и mute. Не пытаться включать звук программно до жеста: Chrome ставит видео на паузу при unmute без user gesture (есть pause-guard с откатом). Скролл колёсиком жестом не считается — на десктопе звук включится только после клика/клавиши. На iOS fade не работает — `video.volume` игнорируется, звук включается/выключается сразу.
- Каталог активных товаров [[product]]: видимый H1, чипы категорий (ведут на страницы категорий), поиск по локализованному и русскому названию (понимает `?search=` из адреса), галерея со свайпом, выбор размера, скидочные цены, похожие товары (`relatedProducts`).
- Карточка товара в сетке — настоящая ссылка на страницу товара. Обычный клик открывает модалку, клик с Ctrl/Cmd или средней кнопкой — страницу в новой вкладке.
- **Остатки скрыты.** Наружу из `lib/catalog.ts` уходит только `inStock` по размерам, без чисел. Закончившиеся размеры зачёркнуты, товар без остатков помечен «Нет в наличии». Точные остатки видны только в админке. `GET /api/products` отдаёт `sizes[].quantity`, поэтому с 2026-10-10 он доступен только админу (`middleware.ts`).
- Корзина хранится в `localStorage` (`minawear-cart`) и общая для главной и страниц товаров. В корзине хранится русское название товара (так заказ понятен владельцу), а показывается локализованное.
- **Оформление заказа — через WhatsApp**: корзина сериализуется в текст сообщения на номер магазина. Заказ затем вручную вносится админом как [[sale]].
- Счётчик посещений: `POST /api/page-visits` пишет документ PageVisit (модель `models/PageVisit.ts` — только timestamp).
- Карточки каталога — 88% непрозрачности (100% при hover и подсветке орбом).

## Орб-помощник

`components/ShoppingOrb.tsx` (поведение) + `components/orbLines.ts` (реплики) + `components/SiriSheetOrb.tsx` (визуал). Визуал — WebGL-орб «Siri Sheet» из VoiceOrbs (MIT, атрибуция в `README.md`), без npm-зависимостей; цвета rose, 92 px на мобильных и 116 px на десктопе.

- **Следует за пальцем.** Касание экрана (кроме nav, полей ввода, модалок и `[data-orb-ignore]`) — и орб летит к пальцу и ведёт его, держась выше и сбоку, чтобы палец его не закрывал. Слушатели passive, скролл не блокируется. При движении орб вытягивается по скорости. Отпустил палец — орб ждёт, пока скролл успокоится, садится на ближайшую карточку, подсвечивает её и комментирует.
- **Мышь.** Орб следует за курсором; задержка над карточкой ~0.45 сек — подсветка и реплика.
- **Быстрый свайп** (палец > 1500 px/с или скролл > 3000 px/с) — сначала реакция вроде «Притормози — тут красиво», не чаще раза в 25 сек.
- **Тап по самому орбу** — следующая карточка по порядку (с автоскроллом, если карточка не помещается). Тап по облачку — открыть товар из реплики.
- **Реплики из фактов, а не из названий.** Для подсвеченного товара по кругу: особенность ткани и кроя (атлас, флис, драп, по фигуре…), размеры в наличии, скидка (было/стало/выгода), этот же товар в других цветах, пара верх↔низ (сначала из `relatedProducts`), цена. Простой > 2 сек без подсветки — вопросы («рубашки или джинсы?», «собираем образ?»), советы по товарам на экране, скидки, готовые пары с общей ценой. После закрытия модалки — реплика-продолжение про этот товар. Товар без остатков — орб так и говорит и предлагает замену в наличии: сначала из той же категории, потом того же типа (верх/низ), потом любую.
- Генератор помнит последние 10 реплик и фактов и не повторяется подряд, реплика не длиннее 70 символов. Подряд не больше 3 реплик, потом орб замолкает до следующей активности.
- Первая реплика за сессию — приветствие («Привет! Води пальцем — я подскажу», на десктопе «Наведи на вещь…»), флаг в `sessionStorage`.
- **Три языка.** Словари ru/kk/en в `orbLines.ts`, язык берётся из страницы, названия товаров приходят уже локализованные.
- Слои (fixed): орб — `z-20` поверх сетки с `mix-blend-screen` (над фото читается как свет), под ним rose-скрим для контраста на светлых фото; рамка подсветки карточки — отдельный слой `z-20`; облачко — `z-30`, под navbar (`z-40`) и модалками (`z-50`). `mix-blend-mode` стоит на самом fixed-слое: любой stacking context между ним и сеткой изолировал бы смешение.
- Скрыт (fade-out, `inert`, пауза WebGL-цикла) в hero-зоне, при открытой модалке или корзине и при пустом результате поиска. WebGL-цикл стоит на паузе и вне экрана, и в фоновой вкладке.
- `prefers-reduced-motion`: без полёта и вытягивания, без печати, мгновенный скролл.
- Gotcha для локальной проверки: если dev-оптимизатор `next/image` отдаёт 500 по таймауту на Cloudinary (Node сначала пробует IPv6), запускать dev-сервер с `NODE_OPTIONS=--dns-result-order=ipv4first`.

## Маркетинг

- 15-секундный вертикальный промо-ролик (Reels/TikTok) собран на HyperFrames из реальных фото и цен каталога. Проект лежит в `mina-wear-promo/` в корне репозитория и исключён из git (`.gitignore`): рендеры и медиа весят ~90 МБ. Версия v2 (`renders/minawear-promo-15s-v2.mp4`) смонтирована в бит трека 130 BPM из каталога HeyGen; для музыки нужен HeyGen CLI (`~/.local/bin/heygen`). Версия v3 (2026-10-10): пять 20-секундных концепций (A «Примерочная», B «Взрыв цвета», C «Переписка», D «Вешалка», E «Модный прогноз»), каждая со своим треком и SFX-паком; готовые файлы в `mina-wear-promo/renders/v3/`, проекты в `mina-wear-promo/v3/<slug>/`, общий регламент сборки `mina-wear-promo/v3/BUILD_RULES.md`.
- Контекст для маркетинговых задач — `.agents/product-marketing.md`.
