# Логин для админ-части Mina CRM

Дата: 2026-07-31. Статус: одобрено (вариант «максимально просто»).

## Требования

- Один пользователь — владелец бутика. Креды в env (`ADMIN_LOGIN`, `ADMIN_PASSWORD`), без модели User.
- Сессия 30 дней, фиксированная (без скользящего продления).
- Защитить страницы `/admin/*` и все API, кроме нужных публичной витрине.

## Решение

JWT (HS256, библиотека `jose`, секрет `AUTH_SECRET`) в httpOnly-куке `mina_admin_token` + `middleware.ts`.

### Компоненты

- `lib/auth.ts` — имя куки, выпуск и проверка JWT (edge-совместимо).
- `lib/validations/auth.ts` — Zod-схема логина.
- `POST /api/auth/login` — сверка кредов с env через SHA-256 + `timingSafeEqual`; при неверных кредах задержка 500 мс и 401 («Неверный логин или пароль»); при успехе кука: httpOnly, Secure (prod), SameSite=Lax, maxAge 30 дней.
- `POST /api/auth/logout` — очистка куки.
- `middleware.ts`, matcher `/admin/:path*` и `/api/:path*`:
  - публично: `/api/auth/*`, `GET /api/products` (витрина), `POST /api/page-visits` (счётчик);
  - остальной `/api/*` без валидной куки → 401 JSON;
  - `/admin/*` без валидной куки → redirect `/login?from=<путь>`.
- `app/login/page.tsx` — форма login+password на shadcn/ui (Card, Input, Button, Label), после входа redirect на `from` или `/admin/dashboard`.
- Кнопка «Выйти» внизу sidebar в `AdminNav`.

### Осознанные упрощения

- Пароль в env открытым текстом: доступ к env = доступ к серверу, хешировать нечего защищать.
- Нет rate-limiting кроме задержки 500 мс: один пользователь, перебор по сети упирается в задержку.
- Logout доступен без авторизации (просто чистит куку) — безвреден.

### Ошибки

- Неверные креды — общее сообщение без уточнения, что именно неверно.
- Истёкшая/битая кука — тот же путь, что и её отсутствие (redirect / 401).
- Отсутствие `AUTH_SECRET` в env — ошибка при первом обращении к auth-функциям с понятным текстом.
